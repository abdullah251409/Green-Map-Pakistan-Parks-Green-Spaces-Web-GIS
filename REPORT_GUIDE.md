# Report screenshot checklist
Add your own screenshots to the PDF report after each relevant description:
1. Project folder showing all files.
2. Project open in Visual Studio Code.
3. HTML/CSS/JavaScript source code.
4. GitHub repository created.
5. Files uploaded to GitHub.
6. GitHub Pages settings, if publishing.
7. Live website URL, if published.
8. Website with map loaded.
9. API fetch code or successful browser network/console evidence.
10. Green-space markers and a popup.
11. Search and filters in use.
12. Final working website or error-handling message.

Do not claim a step is completed unless you have completed it. The PDF report includes screenshot placeholders that should be replaced with your own evidence.
